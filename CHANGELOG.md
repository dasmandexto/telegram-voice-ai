## [2.0.0] - 2026-09-20

### ✨ Новые возможности

#### 1. Улучшенная обработка статусов звонков

**Добавлены все возможные статусы:**

- ✅ **answered** - Абонент ответил
- ❌ **no_answer** - Не ответил (таймаут 20 сек) + **автоматический сброс**
- 📵 **unreachable** - Недозвон (абонент не в сети) 🆕
- 📞 **busy** - Занято 🆕
- 🚫 **declined** - Сбросил звонок 🆕
- ❌ **contact_not_found** - Контакт не найден
- ⚠️ **error** - Техническая ошибка

**Было:**
```javascript
// Только 2 статуса
if (answered) {
    // обработка
} else {
    // всё остальное = "no_answer"
}
```

**Стало:**
```javascript
// 7 детальных статусов
switch (callResult.status) {
    case 'answered': ...
    case 'no_answer': ...      // + автосброс после 20 сек
    case 'unreachable': ...    // 🆕 недозвон
    case 'busy': ...           // 🆕 занято
    case 'declined': ...       // 🆕 сбросил
    case 'contact_not_found': ...
    case 'error': ...
}
```

---

#### 2. Автоматический сброс звонка после таймаута

**Проблема (было):**
- Звонок продолжался бесконечно
- Приходилось вручную завершать
- Непонятно когда переходить к следующему

**Решение (стало):**
```javascript
// Ждем ответа 20 секунд
while (Date.now() - startTime < timeout) {
    // проверяем статус
}

// ТАЙМАУТ - автоматически сбрасываем
console.log('⏱️  Таймаут 20 сек - автоматически сбрасываю звонок');
await this.endCall();
return { status: 'no_answer' };
```

**Результат:**
- ✅ Звонок автоматически завершается через 20 секунд
- ✅ Чёткое разделение: no_answer vs unreachable
- ✅ Переход к следующему номеру без задержек

#### 3. Импорт сессий Telegram (session+json / tdata)

**Для аккаунтов без 2FA!**

**Поддерживаемые форматы:**
- 📄 `session.json` - JSON файл с данными сессии
- 📂 `tdata/` - папка Telegram Desktop

**Использование:**
```javascript
const caller = new VoiceAITelegramCallerV2({
    importSessionPath: './session.json',  // или './tdata'
    audioMessageFile: './audio-message.mp3'
});
```

**Автоматическая обработка:**
1. Определяет тип (JSON или tdata)
2. Копирует в `telegram-session/`
3. Использует для авторизации
4. Не требует QR-кода или SMS

**Документация:** [SESSION_IMPORT.md](SESSION_IMPORT.md)

### 🔧 Технические улучшения

#### Новый метод waitForCallAnswerWithStatus()

**Интеллектуальное определение статуса:**
```javascript
async waitForCallAnswerWithStatus() {
    // Проверяем таймер звонка (answered)
    const callTimer = await this.page.$('.call-duration');
    
    // Анализируем текст на экране
    const pageText = await this.page.evaluate(() => document.body.innerText);
    
    // Определяем статус по ключевым словам
    if (pageText.includes('unavailable')) return { status: 'unreachable' };
    if (pageText.includes('busy')) return { status: 'busy' };
    if (pageText.includes('declined')) return { status: 'declined' };
    
    // Таймаут
    if (Date.now() - startTime >= timeout) {
        return { status: 'no_answer' };
    }
}
```

**Преимущества:**
- Точное определение причины отсутствия ответа
- Разделение "не в сети" vs "не ответил"
- Распознавание "занято" и "сбросил"
