### Этап 2: Авторизация (только первый раз)

#### Вариант A: QR-код

1. Откройте Telegram на телефоне
2. Settings → Devices → Link Desktop Device
3. Отсканируйте QR-код

#### Вариант B: Номер телефона

1. Нажмите "Log in by phone number"
2. Введите ваш номер: `+380XXXXXXXXX`
3. Введите код из SMS

**После авторизации:**


## 🧪 Тестовый режим

Для тестирования без реальных звонков:

1. Используйте тестовые номера (например, свой второй номер)
2. Запустите с малым списком (2-3 номера)
3. Проверьте результаты в CSV

**Тестовый phones.txt:**

```
+380501111111  # Ваш тестовый номер 1
+380502222222  # Ваш тестовый номер 2
```

## 💡 Советы для эффективного обзвона

### ✅ Хорошие практики:

1. **Тестируйте на себе** - сначала позвоните на свой номер
2. **Короткое аудио** - 10-15 секунд максимум
3. **Четкая речь** - без шумов и эхо
4. **Вежливое сообщение** - уважайте время людей
5. **Разумные таймауты** - 20 сек достаточно
6. **Задержки между звонками** - минимум 3 сек

### ❌ Избегайте:

1. Массового спама
2. Ночных звонков
3. Слишком длинных сообщений
4. Агрессивных продаж
5. Звонков без согласия

## 🎯 Сценарии использования

### 1. Опрос клиентов

**Аудио:** "Здравствуйте! Вы недавно заказывали у нас. Остались ли вы довольны? Пожалуйста, скажите да или нет."

**Категории:**
- ДА → довольны
- НЕТ → недовольны

### 2. Подтверждение встреч

**Аудио:** "Здравствуйте! Напоминаем о встрече завтра в 14:00. Подтверждаете?"

**Категории:**
- ДА → подтверждено
- НЕТ → отменено

### 3. Квалификация лидов

**Аудио:** "Здравствуйте! Интересует ли вас [продукт/услуга]?"

**Категории:**
- ДА → заинтересован (передать менеджеру)
- НЕТ → не интересует
