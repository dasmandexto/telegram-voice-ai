# 📞 Telegram Auto Caller v3.0 - PRODUCTION READY

Полнофункциональная система автоматического обзвона с интерактивной настройкой.

---

## 🆕 Что нового в v3.0?

### ✨ Интерактивная настройка перед запуском

Больше не нужно редактировать код! Система задаст все вопросы:

```
📋 ШАГ 1: Список номеров → phones.txt
🎵 ШАГ 2: Аудиосообщение → audio-message.mp3
⏱️  ШАГ 3: Таймаут ответа → 15, 20, 30 сек (на выбор)
⏳ ШАГ 4: Задержка между звонками → 3, 5, 10 сек
🌐 ШАГ 5: Прокси → один или несколько с автоматической ротацией
🔐 ШАГ 6: Сессия Telegram → импорт или авторизация
🤖 ШАГ 7: SpamBot проверка → проверка аккаунта после работы
🎙️  ШАГ 8: Voice AI → ваш Whisper + OXXN или заглушка
```

### 🌐 Поддержка прокси с автоматической ротацией

- Один прокси или список из файла
- Автоматическая смена после N звонков (настраивается)
- Поддержка авторизации (username/password)

### 🤖 Проверка через @SpamBot

- Автоматическая проверка аккаунта после обзвона
- Определение статуса: clean / limited / unknown
- Можно отключить в настройках

### 🎙️ Интеграция с вашим Voice AI

- Поддержка Whisper (guff) + OXXN Realtime API
- Простой HTTP API эндпоинт
- Распознавание текста + интонации + эмоции
- Заглушка для тестирования без Voice AI

### ⚙️ Гибкая настройка таймаутов

- Выбор времени ожидания ответа (секунды)
- Настройка задержки между звонками
- Всё через интерактивный интерфейс

## 📊 Возможности

### ✅ Обработка звонков

- **7 детальных статусов:**
  - ✅ answered - ответил
  - ❌ no_answer - не ответил (таймаут + автосброс)
  - 📵 unreachable - недозвон (не в сети)
  - 📞 busy - занято
  - 🚫 declined - сбросил
  - ❌ contact_not_found - не найден
  - ⚠️ error - ошибка

- **Категоризация ответов:**
  - 👍 yes - заинтересован
  - 👎 no - не заинтересован
  - ❓ unclear - неясно

### 🌐 Прокси

- Один или несколько прокси
- Автоматическая ротация после N звонков
- Поддержка HTTP прокси с авторизацией
- Формат: `http://user:pass@host:port`

### 🔐 Авторизация Telegram

- **QR-код** - отсканировать через приложение
- **SMS** - ввести номер и код
- **Импорт сессии** - для аккаунтов без 2FA
  - session.json файл
  - tdata папка Telegram Desktop

### 🎙️ Voice AI

- **Whisper (guff)** - транскрипция речи
- **OXXN Realtime API** - анализ интонаций
- **HTTP API** - простая интеграция
- **Заглушка** - для тестирования без AI

### 🤖 Безопасность

- Проверка через @SpamBot после обзвона
- Автоматическое определение ограничений
- Рекомендации по использованию

## 📁 Структура конфигурации

### Интерактивный режим:

```bash
node voice-ai-caller-v3.js
```

Система сама спросит все параметры.

### Программный режим:

```javascript
const caller = new VoiceAICallerV3({
    // Основное
    phoneListFile: './phones.txt',
    audioMessageFile: './audio-message.mp3',
    
    // Таймауты
    callTimeout: 15000,           // 15 сек ожидания
    delayBetweenCalls: 5000,      // 5 сек между звонками
    
    // Прокси
    proxyServer: 'http://proxy:8080',
    proxyUsername: 'user',
    proxyPassword: 'pass',
    callsBeforeProxyRotation: 20, // Менять каждые 20 звонков
    
    // Сессия
    importSessionPath: './session.json',
    
    // Voice AI
    voiceAIEndpoint: 'http://localhost:3000/api/transcribe',
    
    // SpamBot
    checkSpamBotAfter: true
});
```

## 🎯 Примеры использования

### Пример 1: Базовая настройка (без прокси, без Voice AI)

```bash
npm run start:v3

# В интерактивной настройке:
Прокси? n
Сессия? n (авторизуетесь по QR)
SpamBot? y
Voice AI? n (заглушка)
```

### Пример 2: С прокси

```bash
npm run start:v3

# В интерактивной настройке:
Прокси? y
Введите прокси: http://user:pass@proxy:8080
Менять после: 50 звонков
```

### Пример 3: Множественные прокси из файла

Создайте `proxy.txt`:
```
http://user1:pass1@proxy1:8080
http://user2:pass2@proxy2:8080
http://user3:pass3@proxy3:8080
```

```bash
npm run start:v3

# В интерактивной настройке:
Прокси? y
Введите прокси или путь: proxy.txt
✅ Загружено 3 прокси
Менять после: 20 звонков
```

### Пример 4: С Voice AI (Whisper + OXXN)

Запустите Voice AI сервер:
```bash
node voice-ai-server.js  # ваш сервер
```

Запустите caller:
```bash
npm run start:v3

# В интерактивной настройке:
Voice AI? y
URL: http://localhost:3000/api/transcribe
```

**Инструкция по Voice AI:** [VOICE_AI_INTEGRATION.md](VOICE_AI_INTEGRATION.md)

## 🛡️ Безопасность

### Рекомендации:

1. **Не превышайте 50-100 звонков на аккаунт в день**
2. **Используйте прокси** для защиты IP
3. **Меняйте прокси регулярно** (каждые 20-50 звонков)
4. **Проверяйте SpamBot** после каждого сеанса
5. **Используйте задержки** между звонками (минимум 3 сек)
6. **Не звоните в ночное время** (23:00 - 08:00)

### SpamBot проверка:

Автоматически проверяет:
- Есть ли ограничения на аккаунте
- Заблокирован ли за спам
- Статус репутации
