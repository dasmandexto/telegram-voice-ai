# 📞 Telegram Voice AI Auto Caller v5.0

Полностью пересобранный и оптимизированный проект для автоматического обзвона через Web Telegram с интеграцией **Voice AI**.

## 🌟 Ключевые изменения (Что нового)
- **Идеальный звук:** Бот больше не использует колонки. Звук напрямую транслируется абоненту в звонок (WebRTC AudioContext).
- **Два аудиофайла:** Бот говорит приветствие (1.wav), ждет ответ, записывает голос абонента (Remote Stream) и проигрывает прощание (2.wav).
- **Единый ИИ-сервер:** OXXN (эмоции) и Whisper (распознавание речи) объединены в один удобный Python API. Никаких C++ бинарников.

## 🚀 Быстрый старт

### 1. Подготовка ИИ-Сервера (Python)
Вам потребуется Python 3.8+
`ash
cd ai_server
pip install -r ../requirements.txt
python app.py
`
*Сервер запустится на порту 8000 и скачает модели при первом запуске.*

### 2. Подготовка Бота (Node.js)
Откройте новое окно терминала:
`ash
npm install
npm run install:browsers
`

### 3. Данные для работы
В корне проекта (рядом с package.json) должны быть:
1. Файл phones.txt с номерами (каждый номер с новой строки).
2. Папка sessions/ с вашей сессией Telegram (внутри папки с 	data или session.json).
3. Файлы 1.wav (Приветствие) и 2.wav (Прощание).

### 4. Запуск
`ash
npm start
`
Бот начнет обзвон, транслируя звук в звонок и записывая ответы!
