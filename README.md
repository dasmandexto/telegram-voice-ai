# 📞 Telegram Voice AI Auto Caller v5.0

Полностью пересобранный и оптимизированный проект для автоматической работы с аудио и интеграцией **Voice AI**.

## 🌟 Ключевые изменения (Что нового)
- **Панель управления (UI):** Удобный веб-интерфейс для загрузки `1.wav`, `2.wav` и вставки списка номеров из буфера обмена.
- **Идеальный звук:** Звук напрямую транслируется в поток (WebRTC AudioContext).
- **Два аудиофайла:** Бот воспроизводит приветствие (`1.wav`), записывает голос собеседника (Remote Stream) и проигрывает прощание (`2.wav`).
- **Единый ИИ-сервер:** OXXN (эмоции) и Whisper (распознавание речи) объединены в один удобный Python API.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей Node.js
```bash
npm install
npm run install:browsers
```

### 2. Подготовка ИИ-Сервера (Python)
Вам потребуется Python 3.8+
```bash
cd ai_server
pip install -r ../requirements.txt
python app.py
```
*Сервер запустится на порту 8000 и скачает модели при первом запуске.*

### 3. Веб-Панель Управления (UI)
Для удобной настройки запустите панель управления:
```bash
npm run ui
```
Откройте в браузере: `http://localhost:3000`
- Загрузите `1.wav` (Приветствие) и `2.wav` (Прощание).
- Вставьте список номеров из буфера обмена и нажмите "Сохранить".

### 4. Запуск приложения
```bash
npm start
```
