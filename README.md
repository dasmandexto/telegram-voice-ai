# 📞 Telegram Voice AI Auto Caller v4.0

**Мультиаккаунтная** система автоматического обзвона через Web Telegram с интеграцией **Voice AI** (Whisper GGUF и OXXN) для распознавания речи и анализа интонаций.

> 🚀 **Production Ready** | 👥 **Multi-Account** | 🎙️ **Whisper GGUF** | 🎭 **OXXN Intonation** | 🌐 **Proxy Rotation**

## 🌟 Ключевые возможности

*   **Мультиаккаунтный автообзвон:** Параллельная работа с несколькими аккаунтами Telegram.
*   **Voice AI Интеграция:** Использование Whisper для транскрипции и OXXN для анализа эмоций.
*   **Гибкие настройки:** Поддержка TXT/CSV списков номеров, настраиваемые таймауты и автосброс.
*   **Безопасность и Прокси:** Ротация прокси, импорт сессий (session.json / tdata), проверка через @SpamBot.
*   **Интерактивный CLI:** Удобная настройка и запуск прямо из терминала.

## 🚀 Быстрый старт

### 1. Установка

`ash
git clone https://github.com/YOUR_USERNAME/telegram-voice-ai.git
cd telegram-voice-ai

# Установите зависимости
npm install

# Установите браузер Chromium
npm run install:browsers
`

### 2. Подготовка

Создайте файл со списком номеров phones.txt:
`	ext
+380501234567
+380631234567
`

Поместите ваш аудиофайл udio-message.mp3 в корень проекта.

### 3. Запуск

Используйте основной скрипт последней версии:
`ash
npm run start:v4
# или npm run start:v3 для предыдущей версии
`
Система задаст вам все необходимые вопросы для настройки!

## 🛡️ Безопасность и Лимиты

1.  **Не превышайте 50-100 звонков в день** на один аккаунт.
2.  **Используйте прокси** с автоматической ротацией.
3.  **Не загружайте в Git** файлы сессий (	elegram-session/, session.json), прокси и списки номеров (уже исключены в .gitignore).
