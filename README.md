# 📞 Telegram Voice AI Auto Caller v4.0

**Мультиаккаунтная** система автообзвона через Web Telegram с **Whisper GGUF** и **OXXN** для распознавания речи и анализа интонаций.

> 🚀 **Production Ready** | 👥 **Multi-Account** | 🎙️ **Whisper GGUF** | 🎭 **OXXN Intonation** | 🌐 **Proxy Rotation**

🆕 **v4.0 Multi-Account Edition:**
- ✅ Параллельный автообзвон с множественными аккаунтами
- ✅ TXT/CSV форматы списков номеров
- ✅ Whisper GGUF для распознавания речи
- ✅ OXXN анализ интонаций и эмоций
- ✅ Автораспределение номеров между аккаунтами

## 🎙️ Интеграция Voice AI

### Создайте HTTP API сервер:

```javascript
const express = require('express');
const app = express();

app.post('/api/transcribe', async (req, res) => {
    const audioBuffer = req.body; // WebM аудио из Telegram
    
    // 1. Whisper (guff) для транскрипции
    const transcription = await runWhisper(audioBuffer);
    
    // 2. OXXN Realtime API для интонаций
    const intonation = await analyzeOXXN(audioBuffer);
    
    // 3. Возвращаем результат
    res.json({
        text: transcription.text,        // Обязательно
        sentiment: intonation.sentiment, // Опционально
        emotions: intonation.emotions    // Опционально
    });
});

app.listen(3000);
console.log('🎙️  Voice AI API запущен на http://localhost:3000');
```

## 📊 Статусы звонков

| Статус | Описание | Действие |
|--------|----------|----------|
| ✅ **answered** | Абонент ответил | Проигрываем аудио, слушаем ответ |
| ❌ **no_answer** | Таймаут (не ответил) | Автосброс через N секунд |
| 📵 **unreachable** | Недозвон (не в сети) | Записываем, следующий |
| 📞 **busy** | Занято | Записываем, следующий |
| 🚫 **declined** | Сбросил звонок | Записываем, следующий |
| ❌ **contact_not_found** | Контакт не найден | Записываем, следующий |
| ⚠️ **error** | Техническая ошибка | Логируем, следующий |

### Категории ответов (для answered):

- 👍 **yes** - заинтересован ("да", "угу", "давайте", "хорошо")
- 👎 **no** - не заинтересован ("нет", "не интересно", "не надо")
- ❓ **unclear** - неясно (шум, непонятная речь)

## 🛡️ Безопасность

### ⚠️ Важные правила:

1. **Не превышайте 50-100 звонков/день** на один аккаунт
2. **Используйте прокси** для защиты IP
3. **Меняйте прокси регулярно** (каждые 20-50 звонков)
4. **Проверяйте @SpamBot** после каждого сеанса
5. **Используйте задержки** между звонками (минимум 3 сек)
6. **Не звоните ночью** (23:00 - 08:00)
7. **НЕ КОММИТЬТЕ** сессии, прокси, реальные номера в Git!
