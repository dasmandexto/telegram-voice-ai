# 📞 Telegram Voice AI Auto Caller v6.0

Полностью пересобранный и оптимизированный проект для автоматической работы с аудио и интеграцией **Voice AI**.

## 🌟 Ключевые изменения (Что нового)
- **Панель управления (UI) как основа:** Теперь \
pm start\ запускает веб-панель. Самого бота можно запустить нажатием одной кнопки прямо в браузере!
- **Единая команда установки:** Все зависимости ставятся одной командой \
npm run setup\.
- **Идеальный звук:** Звук напрямую транслируется в поток (WebRTC AudioContext).
- **Единый ИИ-сервер:** OXXN (эмоции) и Whisper объединены в удобный Python API.

---

## 🚀 Быстрый старт

### 1. Установка всех зависимостей (Один клик)
Эта команда установит все нужные Node-модули, системные библиотеки для браузера и загрузит сам браузер.
\\\
npm run setup
\\\

### 2. Подготовка ИИ-Сервера (Python)
Вам потребуется Python 3.8+
\\\
cd ai_server
pip install -r ../requirements.txt
python app.py
\\\
*Сервер запустится на порту 8000 и скачает модели при первом запуске.*

### 3. Запуск Панели Управления и Бота
В новом окне терминала просто напишите:
\\\
npm start
\\\
Откройте в браузере: \http://localhost:3000\
- Загрузите \1.wav\ (Приветствие) и \2.wav\ (Прощание).
- Вставьте список номеров из буфера обмена и нажмите "Сохранить".
- **Нажмите большую зеленую кнопку "🚀 ЗАПУСТИТЬ БОТА"**.
