## 🚀 Как использовать

### Вариант 1: Playwright (РЕКОМЕНДУЕТСЯ)

**Для реального автоматического обзвона.**

```bash
npm install
npm run install:browsers
npm run start:voice-ai
```

### Вариант 2: Voice AI Runtime

**Для разработчиков, которые хотят развернуть на Voice AI платформе.**

Используйте файлы:
- `manifest.json`

### Вариант 3: Демо UI

**Для визуализации и тестирования интерфейса.**

Откройте `index.html` в браузере.

## ✨ Ключевые возможности

### ✅ Реализовано

1. **Автоматизация Web Telegram**
   - Поиск контактов по номеру телефона
   - Инициация голосовых звонков
   - Ожидание ответа с таймаутом (20 сек)
   - Автоматическое завершение звонков

2. **Проигрывание аудио**
   - Поддержка MP3, WAV, OGG, M4A
   - Автоматическое воспроизведение после ответа
   - Передача через WebRTC

3. **Распознавание речи (Voice AI)**
   - Запись входящего аудиопотока
   - Интеграция с STT (Speech-to-Text)
   - Категоризация ответов: ДА / НЕТ / НЕЯСНО

4. **Сохранение результатов**
   - JSON формат (детальные данные)
   - CSV формат (для Excel/Sheets)
   - Консольная статистика

5. **Управление сессией**
   - Сохранение авторизации Telegram
   - Персистентный браузерный контекст
   - Не требует повторной авторизации

6. **Настраиваемость**
   - Таймауты ожидания
   - Задержки между звонками
   - Headless/GUI режимы
   - Voice AI endpoint

### 🔮 Возможные расширения

- Мультиаккаунт (несколько Telegram аккаунтов)
- Интеграция с CRM системами
- Webhook уведомления
- A/B тестирование аудиосообщений

## 📊 База данных

### Таблица: `call_results`

Автоматически создается и заполняется.

| Поле | Тип | Описание |
|------|-----|----------|
| id | text | Уникальный ID |
| phone_number | text | Номер телефона (+380...) |
| call_status | text | answered / no_answer / busy |
| response | text | Полный ответ человека |
| response_category | text | yes / no / unclear |
| call_time | datetime | Время звонка |
| processed | bool | Флаг обработки |

## ⚙️ Конфигурация

### Основные параметры

```javascript
{
  callTimeout: 20000,        // 20 сек ожидания ответа
  callDuration: 30000,       // 30 сек максимальная длительность
  delayBetweenCalls: 3000,   // 3 сек между звонками
  headless: false,           // GUI режим
  audioMessageFile: './audio-message.mp3',
  voiceAIEndpoint: null      // URL Voice AI API
}
```

### Категории ответов

**YES (заинтересован):**
- "да", "угу", "ага", "давайте", "хорошо", "интересно"

**NO (не заинтересован):**
- "нет", "не интересно", "не надо", "отстаньте"

**UNCLEAR (неясно):**
- Непонятная речь, шум, сброс звонка
