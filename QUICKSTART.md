# ⚡ Быстрый старт

Хотите начать обзвон **прямо сейчас**? Следуйте этим шагам:

---

## 📦 1. Установка (5 минут)

```bash
# Установить зависимости
npm install

# Установить браузер
npm run install:browsers
```

---

## 📝 2. Подготовка данных (2 минуты)

### a) Номера телефонов

Откройте файл **`phones.txt`** и замените примеры на реальные номера:

```
+380501234567
+380631234567
+380931234567
```

**Важно:** каждый номер с новой строки, формат `+380XXXXXXXXX`

### b) Аудиосообщение

Положите ваш аудиофайл в корень проекта с именем **`audio-message.mp3`**

Или переименуйте существующий файл в `audio-message.mp3`

---

## 🚀 3. Запуск (1 минута)

```bash
npm run start:voice-ai
```

---

## ✅ 4. Авторизация (только первый раз)

Откроется браузер с Web Telegram:

**Вариант 1: QR-код**
- Откройте Telegram на телефоне
- Зайдите в Settings → Devices → Link Desktop Device
- Отсканируйте QR-код

**Вариант 2: Номер телефона**
- Введите ваш номер телефона
- Введите код из SMS

**После авторизации сессия сохранится** - больше не нужно авторизовываться!

---

## 📞 5. Процесс обзвона

Скрипт автоматически:

1. ✅ Ищет контакт по номеру
2. ✅ Инициирует звонок
3. ✅ Ждет ответа (20 секунд)
4. ✅ Проигрывает аудио
5. ✅ Распознает ответ (да/нет/неясно)
6. ✅ Записывает результат
7. ✅ Переходит к следующему номеру

---

## 📊 6. Результаты

После завершения получите:

- **`call-results.json`** - детальные данные
- **`call-results.csv`** - таблица для Excel/Sheets
- **Статистика в консоли** - общая информация

## ⚙️ Настройки (опционально)

### Изменить таймауты

Откройте `voice-ai-integration.js`, найдите:

```javascript
const caller = new VoiceAITelegramCaller({
    callTimeout: 20000,        // 20 сек ожидания (измените на нужное)
    callDuration: 30000,       // 30 сек разговора (измените на нужное)
    delayBetweenCalls: 3000    // 3 сек между звонками (измените на нужное)
});
```

### Запустить в фоне (без окна браузера)

Установите `headless: true` в конфигурации.

**⚠️ Внимание:** в headless режиме сложнее отлаживать. Используйте только когда всё работает!
