# 🚀 Установка и настройка Telegram Auto Caller

Полное руководство по установке и запуску автоматического обзвонщика через Web Telegram с использованием Playwright.

---

## 📋 Требования

### Обязательные:
- **Node.js** версии 16 или выше ([скачать](https://nodejs.org/))
- **npm** (устанавливается вместе с Node.js)
- **Аккаунт Telegram** (с номером телефона)
- **Браузер Chromium** (установится автоматически через Playwright)

### Рекомендуемые:
- **Операционная система:** Windows 10/11, macOS, Linux
- **RAM:** минимум 4 ГБ
- **Интернет:** стабильное соединение

---

## 🔧 Шаг 1: Установка

### 1.1. Клонирование проекта

Если у вас есть этот проект в архиве, распакуйте его. Если это Git-репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd telegram-auto-caller
```

### 1.2. Установка зависимостей

Откройте терминал/командную строку в папке проекта и выполните:

```bash
npm install
```

### 1.3. Установка браузера Chromium

Playwright автоматически скачает Chromium:

```bash
npm run install:browsers
```

---

## 📝 Шаг 2: Подготовка данных

### 2.1. Список номеров телефонов

Отредактируйте файл **`phones.txt`** и добавьте номера в формате E.164:

```
+380501234567
+380631234567
+380931234567
```

**Важно:**
- Каждый номер с новой строки
- Обязательно начинать с `+`
- Без пробелов и дефисов

### 2.2. Аудиосообщение

Положите ваш аудиофайл в корень проекта с именем **`audio-message.mp3`**

**Поддерживаемые форматы:**
- MP3 (рекомендуется)
- WAV
- OGG
- M4A

**Рекомендации по аудио:**
- Длительность: 10-20 секунд
- Четкая речь, без шумов
- Битрейт: 128 kbps или выше

Если аудиофайл называется иначе, укажите путь в конфигурации (см. ниже).

---

## ⚙️ Шаг 3: Конфигурация

### 3.1. Основные настройки

Файл **`telegram-caller.js`** содержит объект `CONFIG` в начале. Основные параметры:

```javascript
const CONFIG = {
    callTimeout: 20000,        // 20 секунд ожидания ответа
    callDuration: 30000,       // 30 секунд максимальная длительность
    delayBetweenCalls: 3000,   // 3 секунды между звонками
    headless: false            // false = с окном браузера, true = в фоне
};
```

### 3.2. Настройка Voice AI (опционально)

Если используете интеграцию с Voice AI, отредактируйте **`voice-ai-integration.js`**:

```javascript
const caller = new VoiceAITelegramCaller({
    audioMessageFile: './audio-message.mp3',
    voiceAIEndpoint: 'http://localhost:3000/api/voice' // URL вашего Voice AI API
});
```

## 🚀 Шаг 4: Первый запуск

### 4.1. Авторизация в Telegram

**Первый запуск требует авторизации в Telegram Web.**

Запустите скрипт:

```bash
npm start
```

Или напрямую:

```bash
node telegram-caller.js
```

**Что произойдет:**
1. Откроется окно браузера с Web Telegram
2. Вам нужно авторизоваться одним из способов:
   - **QR-код**: отсканируйте через приложение Telegram
   - **Номер телефона**: введите номер и код из SMS

**Важно:** После первой авторизации сессия сохраняется в папке `telegram-session/`. Не удаляйте её!

### 4.2. Тестовый звонок

После авторизации скрипт автоматически начнет обзвон номеров из `phones.txt`.

**Процесс звонка:**
1. Поиск контакта по номеру
2. Открытие чата
3. Инициация звонка
4. Ожидание ответа (20 секунд)
5. Если ответили → переход к следующему шагу
6. Если не ответили → следующий номер

---

## 🎙️ Шаг 5: Запуск с Voice AI

Для проигрывания аудио и распознавания ответов используйте:

```bash
npm run start:voice-ai
```

Или:

```bash
node voice-ai-integration.js
```

**Что происходит при звонке:**
1. Контакт отвечает на звонок
2. **Проигрывается ваше аудиосообщение**
3. Скрипт слушает ответ 10 секунд
4. **Распознается речь** (да/нет/неясно)
5. Результат записывается в базу
6. Звонок завершается

## 🔍 Устранение проблем

### Проблема: "Не найдено поле поиска"

**Решение:**
- Убедитесь, что вы авторизованы в Telegram
- Проверьте URL: должен быть `https://web.telegram.org/k/`
- Попробуйте очистить папку `telegram-session/` и авторизоваться заново

### Проблема: "Кнопка звонка не найдена"

**Решение:**
- Убедитесь, что контакт поддерживает голосовые звонки в Telegram
- Проверьте, что у контакта включена возможность звонков
- Некоторые боты и каналы не поддерживают звонки

### Проблема: "Аудиофайл не найден"

**Решение:**
- Проверьте путь к файлу: `./audio-message.mp3`
- Убедитесь, что файл находится в корне проекта
- Проверьте формат файла (MP3, WAV, OGG)

### Проблема: "Playwright не установлен"

**Решение:**
```bash
npm install
npm run install:browsers
```

### Проблема: Звонки не инициируются

**Решение:**
- Откройте `telegram-caller.js` и установите `headless: false`
- Наблюдайте процесс в окне браузера
- Проверьте селекторы элементов (могли измениться в новой версии Telegram)

## ⚡ Расширенные настройки

### Изменение таймаутов

В `CONFIG` или при создании объекта:

```javascript
const caller = new TelegramCaller({
    callTimeout: 30000,      // 30 секунд ожидания
    callDuration: 60000,     // 1 минута разговора
    delayBetweenCalls: 5000  // 5 секунд между звонками
});
```

### Запуск в фоновом режиме (headless)

```javascript
const CONFIG = {
    headless: true  // Без GUI
};
```

**Примечание:** В headless режиме сложнее отлаживать проблемы. Используйте только когда всё работает.

### Интеграция с вашим Voice AI API

Если у вас есть собственный сервер распознавания речи:

```javascript
const caller = new VoiceAITelegramCaller({
    voiceAIEndpoint: 'http://localhost:3000/api/voice',
    audioMessageFile: './audio-message.mp3'
});
```

**Формат запроса к API:**
- **Метод:** POST
- **Content-Type:** audio/webm
- **Body:** бинарные данные аудио

**Формат ответа API:**
```json
{
  "text": "да, интересно"
}
```

## 🛡️ Безопасность и этика

### ⚠️ ВАЖНО:

1. **Не спамьте** - используйте только для легитимных целей
2. **Соблюдайте законы** - проверьте законы о телемаркетинге в вашей стране
3. **Получите согласие** - звоните только тем, кто согласился получать звонки
4. **Уважайте время** - не звоните ночью или рано утром
5. **Храните данные безопасно** - результаты содержат личную информацию

### Рекомендации:

- Используйте задержку между звонками (минимум 3 секунды)
- Не превышайте 50-100 звонков в день с одного аккаунта
- Давайте людям возможность отписаться
- Записывайте только необходимую информацию
